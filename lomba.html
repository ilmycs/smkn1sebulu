1. TCP/IP Dasar & OSI Layer

TCP/IP adalah kumpulan protokol komunikasi yang menjadi dasar jaringan Internet. OSI Layer digunakan sebagai model konseptual untuk memahami proses komunikasi jaringan.

OSIFungsiContoh
7 ApplicationLayanan aplikasiHTTP, DNS, FTP, SMTP
6 PresentationFormat, enkripsi, kompresiSSL/TLS, encoding
5 SessionMengelola sesi komunikasiSession control
4 TransportPengiriman end-to-endTCP, UDP
3 NetworkAlamat dan routingIP, ICMP
2 Data LinkFrame dan MACEthernet, ARP
1 PhysicalSinyal/media fisikKabel, radio, fiber

TCP vs UDP

  • TCP: connection-oriented, reliable, menggunakan acknowledgement.
  • UDP: connectionless, lebih ringan, tidak menjamin pengiriman.

Konsep IP

Pahami network address, host address, broadcast, gateway, subnet mask/CIDR, private IP, public IP, IPv4 dan IPv6.

Kunci: Layer 2 berhubungan dengan MAC/switching, Layer 3 dengan IP/routing, Layer 4 dengan TCP/UDP dan port.

2. Topologi Jaringan Dasar

Topologi menggambarkan cara perangkat terhubung.

TopologiKarakteristik
StarSemua perangkat menuju switch pusat; mudah dikelola.
BusMenggunakan media bersama; kini jarang digunakan.
RingPerangkat membentuk lingkaran.
MeshBanyak jalur antarperangkat; redundansi tinggi.
TreeStruktur bertingkat dari core ke access.
HybridKombinasi beberapa topologi.
Latihan: Rancang LAN sekolah: Internet → MikroTik → Switch → PC/Access Point. Tentukan IP, gateway, DHCP, dan jalur akses Internet.

3. Instalasi & Administrasi MikroTik RouterOS

Konsep

  • RouterBOARD: perangkat keras MikroTik.
  • RouterOS: sistem operasi jaringan MikroTik.
  • CHR: RouterOS untuk virtual machine/cloud.
  • Winbox, WebFig, SSH dan Terminal sebagai alat administrasi.

Instalasi / Upgrade

  • Gunakan RouterOS yang sesuai dengan arsitektur perangkat.
  • Periksa versi dan paket sebelum upgrade.
  • Buat backup sebelum perubahan besar.
  • Setelah upgrade, periksa interface, IP, route, firewall dan service.

Reset, Backup, Export, Import

/system reset-configuration
/system backup save name=backup-router
/system backup load name=backup-router
/export file=konfigurasi
/import file-name=konfigurasi.rsc
/system package update check-for-updates
Catatan: Jangan melakukan reset/load/import pada router produksi tanpa memahami dampaknya. Simpan backup di lokasi aman.

Administrasi dasar

/system identity set name=R1
/user print
/system resource print
/system routerboard print
/ip service print

4. Interface, Bridge & Switching

  • Interface Ethernet: koneksi kabel.
  • Wireless: koneksi radio.
  • Bridge: menggabungkan interface dalam satu domain Layer 2.
  • Switch chip/hardware offload: pemrosesan switching oleh hardware pada perangkat yang mendukung.
  • STP/RSTP: mencegah loop Layer 2.
  • VLAN: segmentasi jaringan secara logis.
/interface bridge add name=bridge-LAN
/interface bridge port add bridge=bridge-LAN interface=ether2
/interface bridge port add bridge=bridge-LAN interface=ether3
/interface bridge print
/interface bridge port print
Gunakan Bridge untuk kebutuhan Layer 2. Gunakan routing untuk menghubungkan jaringan Layer 3 yang berbeda.

5. IP Address, ARP & DHCP

IP Address

/ip address add address=192.168.10.1/24 interface=bridge-LAN
/ip address print

DHCP Server

/ip pool add name=pool-LAN ranges=192.168.10.10-192.168.10.254
/ip dhcp-server network add address=192.168.10.0/24 gateway=192.168.10.1 dns-server=192.168.10.1
/ip dhcp-server add name=dhcp-LAN interface=bridge-LAN address-pool=pool-LAN
/ip dhcp-server enable dhcp-LAN

DHCP Client

/ip dhcp-client add interface=ether1 disabled=no

ARP

ARP memetakan alamat IPv4 ke MAC Address pada jaringan lokal.

/ip arp print
/ip arp add address=192.168.10.20 mac-address=AA:BB:CC:DD:EE:FF interface=bridge-LAN

6. Routing

Routing menentukan jalur paket dari satu network menuju network lain.

Static Route

/ip route add dst-address=192.168.20.0/24 gateway=192.168.10.2
/ip route print

Default Route

/ip route add dst-address=0.0.0.0/0 gateway=192.168.1.1

Policy Routing

Policy routing dapat memilih jalur berdasarkan sumber, tujuan, routing rule atau marking. Berguna untuk dual-WAN dan pemisahan trafik.

Dynamic Routing

  • OSPF: routing dinamis berbasis link-state.
  • RIP: protokol distance-vector yang sederhana.
  • BGP: routing antar-AS, penting pada jaringan besar/ISP.
Praktik: Bangun 3 router R1-R2-R3. Buat tiga network berbeda dan hubungkan semuanya menggunakan static route. Setelah berhasil, bandingkan konsepnya dengan OSPF.

802.11b2.4 GHzData rate teoritis hingga 11 Mbps.

Pelajari band, frequency, channel, channel width, data rate, signal strength, noise floor, SNR, CCQ dan regulatory domain.

Mode

  • AP/Access Point: menyediakan koneksi wireless.
  • Station/Client: terhubung ke AP.
  • Bridge/Station Bridge: koneksi Layer 2 sesuai kemampuan mode dan perangkat.

Keamanan

Gunakan WPA2/WPA3 bila tersedia dan sesuai perangkat/RouterOS. Gunakan password kuat, batasi management dan pilih frequency yang minim interferensi.

Monitoring

/interface wireless registration-table print
/interface wireless scan wlan1
/interface wireless monitor wlan1

8. Firewall MikroTik

Firewall mengontrol trafik berdasarkan kondisi seperti interface, IP, protocol, port, connection state dan address-list.

Chain

  • input: trafik menuju router.
  • forward: trafik melewati router.
  • output: trafik berasal dari router.

Filter

/ip firewall filter add chain=input connection-state=established,related action=accept
/ip firewall filter add chain=input connection-state=invalid action=drop
/ip firewall filter add chain=input protocol=icmp action=accept
/ip firewall filter add chain=input in-interface=ether1 action=drop

NAT

/ip firewall nat add chain=srcnat out-interface=ether1 action=masquerade
/ip firewall nat add chain=dstnat protocol=tcp dst-port=80 action=dst-nat to-addresses=192.168.10.10 to-ports=80

Address-list

/ip firewall address-list add list=blocked address=192.168.10.50
/ip firewall filter add chain=forward src-address-list=blocked action=drop

FastTrack

FastTrack dapat mempercepat pemrosesan koneksi tertentu, tetapi harus dipahami dampaknya terhadap queue, accounting, firewall dan fitur lain yang membutuhkan pemrosesan paket secara normal.

9. Bandwidth Management: Simple Queue, Burst & PCQ

Simple Queue

/queue simple add name=PC-01 target=192.168.10.20/32 max-limit=5M/10M

Perhatikan urutan limit upload/download sesuai format RouterOS dan konfigurasi perangkat yang digunakan.

Burst

Burst memungkinkan pengguna memperoleh kecepatan lebih tinggi sementara ketika rata-rata trafik berada di bawah burst-threshold.

PCQ

PCQ dapat membagi bandwidth secara otomatis berdasarkan classifier, misalnya src-address untuk upload dan dst-address untuk download.

/queue type add name=pcq-upload kind=pcq pcq-classifier=src-address
/queue type add name=pcq-download kind=pcq pcq-classifier=dst-address
Praktik: Buat jaringan 20 komputer dengan bandwidth Internet 50 Mbps. Rancang pembagian bandwidth menggunakan PCQ dan uji apakah satu komputer dapat menghabiskan bandwidth seluruh jaringan.

10. PPP, IP Pool, PPPoE & VPN

  • PPP: protokol untuk koneksi point-to-point.
  • PPP Profile: parameter koneksi pengguna.
  • PPP Secret: akun autentikasi.
  • IP Pool: kumpulan alamat yang dialokasikan kepada client.
  • PPPoE: PPP over Ethernet.
  • PPTP/SSTP/L2TP: teknologi tunnel/VPN dengan karakteristik keamanan dan penggunaan yang berbeda.

Konsep PPPoE

/ip pool add name=pool-pppoe ranges=10.10.10.10-10.10.10.100
/ppp profile add name=profile-pppoe local-address=10.10.10.1 remote-address=pool-pppoe
/ppp secret add name=user1 password=StrongPassword service=pppoe profile=profile-pppoe
/interface pppoe-server server add service-name=PPPoE interface=bridge-LAN disabled=no
Untuk implementasi produksi, pilih teknologi VPN yang masih didukung dan aman pada versi RouterOS yang digunakan. Hindari protokol lama jika ada alternatif yang lebih kuat.

11. Tunnel & Point-to-Point Network

Tunnel membuat jalur logis melalui jaringan yang sudah ada.

  • EoIP: membawa Ethernet melalui tunnel MikroTik.
  • IPIP: tunnel IP over IP.
  • GRE: tunnel untuk membawa trafik Layer 3.
  • VXLAN: virtualisasi Layer 2 di atas jaringan Layer 3 pada skenario yang sesuai.

Pelajari juga MTU, MSS, addressing point-to-point, routing melalui tunnel, serta keamanan tunnel.

Praktik: Hubungkan dua LAN berbeda melalui tunnel. Pastikan kedua LAN dapat melakukan ping dan routing dengan benar.

13. Web Proxy

Web Proxy berfungsi sebagai perantara permintaan web. Pelajari konsep proxy, cache, access control, transparent proxy, redirect dan monitoring.

Fitur proxy/cache dan dukungan protokol web berubah mengikuti versi RouterOS. Uji pada versi yang digunakan sebelum menerapkannya pada jaringan produksi.

Konsep Lab

  1. Aktifkan proxy pada router lab.
  2. Tentukan port proxy.
  3. Uji client menggunakan proxy manual.
  4. Pelajari access list dan cache.
  5. Amati penggunaan CPU, RAM dan trafik.

14. Keamanan MikroTik

  • Gunakan password administrator yang kuat.
  • Buat user berdasarkan kebutuhan dan privilege.
  • Nonaktifkan service yang tidak digunakan.
  • Batasi akses Winbox/SSH/WebFig dari jaringan management.
  • Gunakan firewall untuk melindungi input router.
  • Matikan MAC-Telnet/MAC-Winbox jika tidak dibutuhkan.
  • Kelola Neighbor Discovery.
  • Simpan backup di lokasi aman.
  • Monitor log dan percobaan akses.
  • Update RouterOS dengan prosedur backup dan pengujian yang benar.

16. Monitoring & Troubleshooting

Metode troubleshooting berlapis

  1. Physical: kabel, power, link, konektor.
  2. Data Link: MAC, bridge, VLAN, loop.
  3. Network: IP, subnet, gateway, route.
  4. Transport: TCP/UDP, port, connection.
  5. Application: DNS, HTTP, service.

Perintah penting

/interface print
/ip address print
/ip route print
/ip arp print
/ip dhcp-server lease print
/ip firewall connection print
/ip firewall filter print stats
/ip firewall nat print stats
/queue simple print stats
/log print
/system resource print
Studi kasus: Client mendapat IP DHCP tetapi tidak bisa Internet. Periksa: DHCP → IP client → gateway → ARP → default route → DNS → NAT → firewall → interface WAN.

17. Hotspot, RADIUS & User Management

  • Hotspot menyediakan autentikasi pengguna melalui captive portal.
  • RADIUS menyediakan autentikasi/otorisasi terpusat.
  • User Manager dapat digunakan pada skenario yang didukung untuk pengelolaan user.

Materi latihan: membuat profile user, membatasi bandwidth, mengatur waktu akses, membuat voucher dan menghubungkan autentikasi ke RADIUS.

18. Scripting & Automation RouterOS

RouterOS menyediakan scripting untuk otomatisasi pekerjaan administrasi.

:log info "Monitoring Router"
:local cpu [/system resource get cpu-load]
:log info ("CPU Load: " . $cpu . "%")

Pelajari variable, condition, loop, scheduler, logging, script permissions dan automation yang aman.

Jangan menjalankan script yang tidak dipahami pada router produksi. Selalu uji pada lab.

20. Evaluasi Pembelajaran

1. Layer OSI yang menangani routing adalah?

A. Physical   B. Data Link   C. Network   D. Application

2. Chain firewall untuk trafik yang menuju router adalah?

A. forward   B. input   C. output   D. nat

3. Fungsi DHCP Server?

Memberikan konfigurasi IP secara otomatis kepada client.

4. Apa fungsi masquerade?

Melakukan source NAT dengan mekanisme yang sesuai untuk alamat keluar yang dapat berubah, umum digunakan pada koneksi Internet.

5. Apa fungsi static route?

Menentukan jalur routing yang dikonfigurasi secara manual.

6. Apa kegunaan Simple Queue?

Mengatur dan membatasi bandwidth berdasarkan target/parameter queue.

7. Apa fungsi ARP?

Memetakan IPv4 address ke MAC address pada jaringan lokal.

8. Mengapa firewall input penting?

Untuk mengontrol akses menuju router itu sendiri.

9. Apa tujuan OSPF?

Menyediakan routing dinamis berbasis link-state.

10. Sebutkan minimal 5 tool troubleshooting RouterOS.

Ping, Traceroute, Torch, Packet Sniffer, Log, Profile, Netwatch, dan lainnya.

BAB 1 — Dasar Jaringan

1.1 Konsep LAN, WAN dan Internet

  • LAN: jaringan pada area terbatas seperti laboratorium atau sekolah.
  • WAN: menghubungkan jaringan yang berjauhan.
  • Internet: jaringan global yang menghubungkan banyak jaringan.

IPv4 terdiri dari 32 bit, ditulis dalam empat oktet. Contoh: 192.168.10.1/24.

BAB 2 — MikroTik RouterOS

2.1 Akses Router

  • WinBox — administrasi grafis.
  • WebFig — administrasi melalui browser.
  • CLI — sangat penting untuk lomba karena cepat dan presisi.

2.2 Perintah Dasar CLI

/system identity set name=ROUTER-OLIMPIADE
/interface print
/ip address print
/ip route print
/ip firewall filter print
/ip firewall nat print
/export
/system backup save name=backup-olimpiade

2.3 Safe Mode

Safe Mode membantu mencegah konfigurasi yang menyebabkan koneksi administrasi terputus. Biasakan melakukan perubahan kritis dengan metode yang dapat dikembalikan.

2.4 Reset

Reset menghapus konfigurasi tertentu sesuai pilihan. Jangan melakukan reset pada router produksi tanpa backup dan persetujuan.

BAB 3 — IP Address & Routing

3.1 Memberikan IP

/ip address add address=192.168.10.1/24 interface=ether2
/ip address print

3.2 Default Route

/ip route add dst-address=0.0.0.0/0 gateway=192.168.1.1

3.3 Static Route

/ip route add dst-address=10.10.20.0/24 gateway=10.10.10.2

3.4 Konsep routing

  • Connected route dibuat otomatis ketika interface memiliki IP.
  • Default route digunakan ketika tidak ada route yang lebih spesifik.
  • Distance digunakan untuk memilih jalur ketika terdapat beberapa route.
Urutan troubleshooting: cek interface → IP address → ARP → route → gateway → DNS → firewall → NAT.

BAB 4 — DHCP & DNS

4.1 DHCP Server

/ip pool add name=pool-lan ranges=192.168.10.10-192.168.10.200
/ip dhcp-server add name=dhcp-lan interface=ether2 address-pool=pool-lan
/ip dhcp-server network add address=192.168.10.0/24 gateway=192.168.10.1 dns-server=192.168.10.1
/ip dhcp-server enable dhcp-lan

4.2 DHCP Client

/ip dhcp-client add interface=ether1 disabled=no

4.3 DNS

/ip dns set allow-remote-requests=yes servers=1.1.1.1,8.8.8.8
/ip dns print

4.4 Static Lease

Static lease mengikat MAC address tertentu dengan IP tertentu. Berguna untuk server, printer, AP dan perangkat penting.

BAB 5 — NAT

5.1 Masquerade

/ip firewall nat add chain=srcnat out-interface=ether1 action=masquerade

5.2 dst-nat / Port Forwarding

/ip firewall nat add chain=dstnat in-interface=ether1 protocol=tcp dst-port=80 \
action=dst-nat to-addresses=192.168.10.10 to-ports=80

5.3 Konsep penting

  • srcnat mengubah sumber trafik.
  • dstnat mengubah tujuan trafik.
  • masquerade cocok untuk koneksi WAN dengan IP dinamis.
  • Port forwarding perlu dipadukan dengan firewall filter yang sesuai.

BAB 6 — Firewall MikroTik

6.1 Chain

ChainFungsi
inputTraffic menuju router itu sendiri
forwardTraffic yang melewati router
outputTraffic yang berasal dari router

6.2 Connection State

State umum: established, related, new, invalid.

/ip firewall filter
add chain=input connection-state=established,related action=accept
add chain=input connection-state=invalid action=drop
add chain=input in-interface=ether1 action=drop

6.3 Address List

/ip firewall address-list add list=blocked address=192.168.10.50
/ip firewall filter add chain=forward src-address-list=blocked action=drop
Perhatian: aturan firewall diproses dari atas ke bawah. Kesalahan urutan rule sering menjadi sumber kegagalan konfigurasi.

BAB 7 — VLAN

7.1 Konsep

VLAN memisahkan jaringan secara logis walaupun menggunakan infrastruktur switch yang sama.

INTERNET | [MikroTik] | TRUNK | [Switch] | | | V10 V20 V30 Guru Siswa Server

7.2 Contoh Interface VLAN

/interface vlan
add name=vlan10-guru vlan-id=10 interface=bridge
add name=vlan20-siswa vlan-id=20 interface=bridge
add name=vlan30-server vlan-id=30 interface=bridge

/ip address
add address=10.10.10.1/24 interface=vlan10-guru
add address=10.10.20.1/24 interface=vlan20-siswa
add address=10.10.30.1/24 interface=vlan30-server

7.3 Materi lomba

  • Access port vs trunk.
  • VLAN ID.
  • Bridge VLAN Filtering.
  • Inter-VLAN routing.
  • Management VLAN.

BAB 8 — Wireless

  • AP: access point untuk menyediakan koneksi wireless.
  • Station: client wireless.
  • SSID: nama jaringan.
  • Frequency & channel width memengaruhi performa.
  • Security profile digunakan untuk autentikasi dan enkripsi.

Checklist optimasi

  1. Gunakan channel yang minim interferensi.
  2. Atur channel width sesuai kebutuhan.
  3. Gunakan keamanan modern yang didukung perangkat.
  4. Perhatikan posisi AP, daya pancar dan jumlah client.
  5. Uji dengan ping dan throughput.

BAB 9 — Bridge

Konsep

Bridge menggabungkan beberapa interface menjadi satu domain Layer 2. Dalam desain VLAN modern, bridge VLAN filtering menjadi konsep penting.

/interface bridge add name=bridge-lan
/interface bridge port
add bridge=bridge-lan interface=ether2
add bridge=bridge-lan interface=ether3
/interface bridge print
/interface bridge port print

STP/RSTP

STP/RSTP membantu mencegah loop Layer 2. Pahami root bridge, path cost dan perubahan topologi.

BAB 10 — PPPoE

PPPoE Server

/ip pool add name=pppoe-pool ranges=10.20.0.10-10.20.0.200
/ppp profile add name=profile-pppoe local-address=10.20.0.1 \
remote-address=pppoe-pool rate-limit=10M/10M
/ppp secret add name=user1 password=rahasia profile=profile-pppoe
/interface pppoe-server server add interface=bridge-lan service-name=OLIMPIADE \
default-profile=profile-pppoe disabled=no

PPPoE sering digunakan untuk autentikasi pelanggan dan pembagian bandwidth.

BAB 11 — Bandwidth Management

Simple Queue

/queue simple add name=CLIENT-1 target=192.168.10.10/32 max-limit=5M/5M

Konsep

  • max-limit: batas maksimum.
  • limit-at: bandwidth minimum yang dijamin dalam kondisi tertentu.
  • Burst: memungkinkan penggunaan bandwidth lebih tinggi untuk periode tertentu.
  • PCQ: membantu pembagian bandwidth secara dinamis.
  • Queue Tree: cocok untuk desain manajemen trafik yang lebih kompleks.
Dalam lomba, pahami bukan hanya cara membuat queue, tetapi juga mengapa trafik tidak mencapai target bandwidth.

BAB 12 — Routing Lanjutan

OSPF

OSPF adalah dynamic routing protocol berbasis link-state. Materi yang perlu dikuasai: neighbor, Router ID, area, cost, LSDB dan route selection.

/routing ospf instance print
/routing ospf area print
/routing ospf interface-template print

Konsep OSPF

  • Router membentuk adjacency dengan neighbor.
  • Informasi link dipelajari melalui LSDB.
  • SPF digunakan untuk menentukan jalur terbaik.
  • Cost memengaruhi pemilihan jalur.

BAB 13 — Load Balancing & Failover

+-- ISP 1 | LAN -- MikroTik | +-- ISP 2

Metode

  • ECMP.
  • PCC (Per Connection Classifier).
  • Recursive routing untuk gateway checking.
  • Failover berdasarkan distance dan health check.

Konsep PCC

PCC membagi koneksi ke beberapa jalur berdasarkan classifier tertentu. Tujuan utamanya adalah membagi koneksi, bukan memecah satu sesi TCP menjadi dua ISP secara sembarang.

Failover

ISP utama digunakan selama sehat. Ketika gateway/path utama gagal, route cadangan mengambil alih.

BAB 14 — VPN

Jenis yang perlu dipahami

  • L2TP/IPsec.
  • SSTP.
  • WireGuard.
  • Site-to-site VPN.
  • Remote access VPN.

Konsep troubleshooting

  1. Pastikan IP publik/reachability.
  2. Pastikan port/protokol tidak diblokir.
  3. Cek konfigurasi peer/client.
  4. Cek route menuju subnet VPN.
  5. Cek firewall.
  6. Uji ping antar-subnet.

Studi Kasus Olimpiade — Jaringan Sekolah

INTERNET | +-----+-----+ | MikroTik | +-----+-----+ | TRUNK | +----+----+ | Switch | +-------+----+----+-------+ | | | VLAN 10 VLAN 20 VLAN 30 Guru Siswa Server 10.10.10.0/24 10.10.20.0/24 10.10.30.0/24

Tugas

  1. Buat bridge dan VLAN 10, 20, 30.
  2. Buat gateway masing-masing VLAN.
  3. Buat DHCP untuk VLAN Guru dan Siswa.
  4. Konfigurasikan DNS.
  5. Berikan akses internet melalui NAT.
  6. Blokir akses siswa menuju management router.
  7. Izinkan siswa menuju internet.
  8. Izinkan VLAN Guru mengakses Server.
  9. Batasi bandwidth siswa.
  10. Uji seluruh konektivitas dan dokumentasikan hasil.

Latihan Soal Olimpiade

  1. Apa fungsi default route?
  2. Apa perbedaan chain input dan forward?
  3. Mengapa masquerade umum digunakan pada WAN dengan IP dinamis?
  4. Berapa host usable pada subnet /27?
  5. Apa fungsi VLAN?
  6. Apa perbedaan access port dan trunk?
  7. Apa tujuan RSTP?
  8. Apa fungsi DHCP Server?
  9. Apa kegunaan Address List pada firewall?
  10. Apa perbedaan src-nat dan dst-nat?
  11. Apa fungsi OSPF?
  12. Apa tujuan PCC pada dual WAN?
  13. Apa fungsi recursive routing pada skenario failover?
  14. Tool MikroTik apa yang digunakan untuk melihat trafik secara real-time?
  15. Jika client dapat ping IP publik tetapi tidak dapat membuka domain, bagian apa yang perlu diperiksa terlebih dahulu?

Kunci Jawaban Singkat

  1. Jalur default ketika tidak ada route yang lebih spesifik.
  2. Input menuju router; forward melewati router.
  3. Karena dapat menyesuaikan perubahan IP sumber WAN.
  4. 30 host usable.
  5. Memisahkan jaringan secara logis.
  6. Access biasanya membawa satu VLAN; trunk membawa beberapa VLAN bertag.
  7. Mencegah loop Layer 2 dan mempercepat konvergensi dibanding STP klasik.
  8. Memberikan konfigurasi IP otomatis kepada client.
  9. Mengelompokkan IP/entitas untuk digunakan oleh rule.
  10. src-nat mengubah sumber; dst-nat mengubah tujuan.
  11. Dynamic routing link-state.
  12. Membagi koneksi ke beberapa jalur.
  13. Mendeteksi kesehatan jalur secara lebih nyata berdasarkan tujuan/reachability.
  14. Torch.
  15. DNS configuration/reachability.
